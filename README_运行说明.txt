MP3 Player — 运行说明

1) 直接运行
- 打开 app 文件夹，双击 MP3Player.exe。
- 首次启动稍慢属正常。

2) 兼容范围
- Windows 10/11 x64。
- 支持的音频格式：mp3 / wav / ogg / flac / m4a / aac / wma / ape。

3) 目录说明
- app\     : 可运行软件目录（MP3Player.exe）。
- source\  : 源码（main.py / player_page.py / theme.py / requirements.txt）。

4) 功能说明
- 打开文件夹：点击左侧「打开文件夹…」、菜单「文件 → 打开文件夹…」（Ctrl+O），
  或将文件夹直接拖入窗口。
- 左侧文件树：像 VSCode 一样浏览目录，单击文件夹即在右侧显示其中的音乐列表；
  双击树中的音频文件可直接播放。
- 音乐列表：显示序号 / 曲名 / 艺术家 / 时长；双击任意行开始播放；
  文件名形如 "歌手 - 歌名.ext" 时自动拆分艺术家与曲名。
- 播放模式：点击模式按钮循环切换 —— 顺序播放 → 列表循环 → 单曲循环 → 随机播放。
- 基本控制：上一首 / 播放-暂停 / 下一首；进度条可拖动跳转；
  音量滑条可调；空格键也可播放/暂停。

5) 备注
- 时长列在歌曲实际播放后自动填充（--:-- 表示尚未加载过）。
- 若个别文件无法播放（编码不支持），状态栏会给出提示，跳过即可。
